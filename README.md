# Multi-Tenant SaaS Platform

This project provides a complete multi-tenant SaaS platform with backend and frontend components.

## Project Structure

- `saas-backend/` - Java Spring Boot application
- `frontend/` - Angular application
- `database/` - SQL schema
- `docs/` - Documentation

## Getting Started

1. Clone the repository.
2. Set up the backend as described in `docs/README.md`.
3. Set up the frontend as described in `docs/README.md`.
4. Run the database schema in `database/schema.sql`.

## Features

- Multi-tenancy support
- Tenant management APIs
- User authentication
- Scalable architecture
